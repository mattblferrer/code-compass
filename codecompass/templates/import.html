Only date, title, and outcome are required.

How rows are read

  • A row with a link is matched to the problem with that link. A row without one is matched by its exact title.
  • A row that matches no problem becomes a new custom problem if it has a difficulty and patterns, separated by semicolons.
  • Rows that repeat an attempt already saved are skipped, so importing the same file twice adds nothing.
  • Invalid rows are skipped and listed with the result; the valid rows are still imported.
